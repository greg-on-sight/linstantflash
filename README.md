# L’Instant Flash — Template maître V2 / Octobre 2026

## Fichiers
- `index.html` : structure stable du site
- `style.css` : charte graphique responsive
- `script.js` : affichage automatique des rubriques
- `contenu.json` : contenu mensuel et activation des rubriques
- `articles/` : dossiers longs
- `contributions/` : fiche pour déléguer des rubriques
- `images/` : visuels

## Mise en ligne GitHub
Importer tout le contenu de ce dossier à la racine du dépôt `linstantflash`, en conservant les sous-dossiers.

Ensuite, dans GitHub : Settings > Pages > Build and deployment > Deploy from a branch > `main` > `/ (root)` > Save.
